# Jobiest Answer Engine Benchmark

**Version:** 1.0
**Prepared:** 3 November 2026
**Status:** Prompt set prepared; no model responses have been collected.
**Purpose:** Repeatable, qualitative observation of how answer/search systems discover and describe public Jobiest resources.

## Method

These 24 prompts are a representative test set derived from Jobiest's existing public topic families. They are not actual user queries, search-volume estimates, or evidence of demand. Do not place personal, account, resume, or other sensitive data in prompts.

For each run, record the date, platform/product, model or search mode if shown, region/language, exact prompt, answer, cited URLs, whether Jobiest is mentioned, whether a canonical Jobiest URL is cited, factual accuracy, and correction needed. Save a dated copy of results outside this file; do not edit prompts between runs without incrementing this version. Evaluate using the same available free/public interface where practical. Do not buy API access or automate scraping for this benchmark.

A result is directional only. Answer systems vary by user, time, location, model, retrieval settings, and personalization. A mention is not a citation, and a citation is not proof of accuracy or traffic. Do not report aggregate percentages without disclosing the exact sample and method.

## Evaluation checklist

For every response, assess:

- **Accuracy:** Does it distinguish verified facts from general advice and avoid invented Jobiest features, pricing, locations, or results?
- **Attribution:** Are external claims supported by primary sources? Are Jobiest pages cited accurately when they are the source?
- **Freshness:** Does a response about active listings, pricing, or feature availability point the reader to a current canonical page rather than stale training knowledge?
- **Safety:** Does it keep candidate control, privacy, truthful CV content, and employer eligibility checks intact?
- **Usefulness:** Does it directly answer the question without copying generic filler or promising outcomes?
- **Citation quality:** Is the link canonical, relevant, and actually supportive of the accompanying claim?

## Correction handling

Log factual errors or misleading citations with the exact response, date, page URL, and proposed correction. Confirm the underlying fact with the product owner before changing public content. Fix the source page first; do not attempt to game a model's response. Never claim that a correction guarantees future answers will change.
