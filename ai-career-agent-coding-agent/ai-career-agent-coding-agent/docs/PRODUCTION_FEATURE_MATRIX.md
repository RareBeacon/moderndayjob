## Security posture summary (verified this audit)

- **Unauthenticated access control**: 68 endpoints swept; all protected endpoints return 401/403/429 — the 8 routes that returned 500 were fixed, deployed, and re-verified live (401 UNAUTHENTICATED).
- **User data isolation**: cross-user probes with random UUIDs → 404/401, never other users' data; all 41 DB tables RLS-enabled; server routes scope every query by `user_id`.
- **Secrets**: repo scan of 664 tracked files clean; no `.env` files tracked; service-role key not present in any tracked file; client bundles contain exactly one JWT — the public anon key.
- **Anti-enumeration**: login errors byte-identical for wrong-password vs unknown-account; forgot-password always 200.
- **Webhook security**: Flutterwave webhook rejects missing/fake signatures (401, timing-safe compare) and re-verifies transactions server-side.
