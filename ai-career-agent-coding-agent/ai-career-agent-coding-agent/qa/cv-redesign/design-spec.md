## G. Limitations and licensing

Fonts are approximated with system serif/sans/mono stacks and licensed DM Sans/Space Grotesk where available; exact proprietary fonts are not bundled. Photos are generated as neutral SVG placeholders, not copied. Bundle references (06) and multi-page sets are represented by their primary CV page. Decorative bitmap textures are recreated with CSS/SVG, not as image assets. Where export (PDF/DOCX) cannot preserve a texture (e.g., torn edge, translucent overlay), a flat colour fallback is used and documented per template.

## H. Colour accuracy

Hex values above are sampled approximations; template code stores them as CSS variables so future fine-tuning does not require structural changes. The palette audit is the source of truth for implementation and verification.
