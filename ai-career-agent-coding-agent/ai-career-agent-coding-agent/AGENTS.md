# Agent Instructions

1. Read `START_HERE.md`.
2. Read every document under `docs/` before implementation.
3. Treat the documented architecture as the source of truth.
4. Do not weaken security to make a feature work.
5. Do not put secrets in source code, Git, frontend bundles, logs or database plaintext.
6. Do not add Gmail inbox access or email OAuth scopes.
7. Do not trust frontend entitlement state.
8. Do not skip tests for security, billing, quota or tenant isolation.
9. If a material architecture change is required, document it and stop for approval instead of silently changing the design.
